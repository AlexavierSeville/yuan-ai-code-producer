# Vite 配置（必须满足）
- **base**：`'./'`（支持子路径部署）  
- **@ 别名**：指向 `./src`  
- **ESM**：使用 Node ESM 语法与路径工具  
- **路由**：**Hash 模式**，避免服务端路由问题  
- **环境变量**：如有使用，仅可用 `import.meta.env`，不得使用 `process.env`  

**示例（必须等价，不得遗漏 import）**：
```js
// vite.config.js
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { fileURLToPath, URL } from 'node:url'

export default defineConfig({
  base: './',
  plugins: [vue()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    }
  }
})
```

---

# 路由配置（必须为 Hash）
```js
// src/router/index.js
import { createRouter, createWebHashHistory } from 'vue-router'

const routes = [
  { path: '/', name: 'home', component: () => import('@/pages/Home.vue') },
  { path: '/about', name: 'about', component: () => import('@/pages/About.vue') }
]

export const router = createRouter({
  history: createWebHashHistory(),
  routes
})

export default router
```

# package.json（锁定版本 + ESM + 脚本）
- 使用 **精确版本**（如 `"4.5.3"`），**不要**写 `^` 或 `~`。  
- 包含 `"type": "module"`，确保 ESM 运行。  
- 仅保留最小脚本集：`dev`、`build`。  

**示例（必须等价）**：
```json
{
  "name": "demo-vue3-app",
  "private": true,
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "vite build"
  },
  "engines": {
    "node": ">=18.0.0"
  },
  "dependencies": {
    "vue": "3.4.21",
    "vue-router": "4.3.2"
  },
  "devDependencies": {
    "@vitejs/plugin-vue": "4.5.2",
    "vite": "4.5.3"
  }
}
```

> 允许在同一小版本线内替换为等价且稳定的具体号（如 `3.4.27` / `4.3.3` / `4.5.5`），但**必须是固定数字**。

# 入口与挂载（构建常见失败点兜底）
- `index.html`：确保存在 `<div id="app"></div>` 与 `type="module"` 的入口脚本。  
- `main.js`：  
  ```js
  import { createApp } from 'vue'
  import App from './App.vue'
  import router from '@/router'
  import '@/styles/base.css'

  createApp(App).use(router).mount('#app')
  ```
- 资源路径：所有静态资源与路由必须在 `base: './'` 与 **Hash 模式**下可正常访问。  
- 不使用绝对 `href="/"` 等会破坏子路径部署的链接，使用路由跳转或相对路径。

# 常见失败源与规避（必须遵守）
- **缺少 `fileURLToPath/URL` 导致别名无效** → 已在模板强制引入。  
- **使用绝对路径/History 路由导致子路径 404** → 强制 Hash + `base: './'`。  
- **未设 `type: module` 导致 Vite/ESM 报错** → package.json 强制设置。  
- **版本飘逸（^ ~）造成不可复现构建** → 一律固定具体版本号。  
- **使用 `process.env`** → 一律改为 `import.meta.env`。  
- **引入多余生态（TS/ESLint/Prettier/UI 库）** → 全部禁止。
